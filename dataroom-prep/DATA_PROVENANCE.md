# Data provenance and contractual controls

See `data_sources.json` and `DATA_SOURCE_REGISTRY.md`. Public access does not imply
unrestricted copying or resale. UNKNOWN means no verified right is established.

Company resolution uses public-name candidates and supplied identifiers; source
associations have confidence and mismatch checks. Ambiguous entities are not
silently selected. Wikipedia is supporting identity/age evidence, not audited
financials. SEC evidence is applicable to filers only. Census is national industry
context. Missing LEI, filings or jobs is not financial distress.

Reports distinguish observation time from retrieval time and retain source IDs,
links, evidence hash, model/configuration and scoring inputs when available.
Historical reconstruction is only possible during configured retention.

Configured licensed credentials no longer imply permission or live evidence.
Operator `PROVIDER_PERMISSIONS_JSON` must include a contract reference and approved
scoring, raw/derived display and retention rights compatible with report retention.
Narrower contracts fail closed until an appropriate redacted path exists. Monitoring
requires its own permission. Customer API refuses licensed redistribution. Codat
remains excluded because account-specific consent/cache isolation is unfinished.
Model development and historical-analysis rights default false and are not used
by the runtime. Schedule retention daily before permitting licensed collection.

Source links should accompany every displayed evidence excerpt. Wikipedia reuse
can require attribution and share-alike; the exact material/license must be reviewed.
No legal clearance is inferred from this registry. Configure an honest automated
User-Agent/contact; the previous invented research mailbox was removed.
