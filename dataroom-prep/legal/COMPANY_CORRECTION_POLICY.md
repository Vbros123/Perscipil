# Company Data Correction Policy — draft 2026-09-20
Authenticated users can select an owned saved report and report wrong entity,
address, company facts, legal-event association, stale evidence, source errors or
other issues. Store report reference, evidence hash, requester account, timestamp,
reason and details. Do not submit sensitive personal information.
Requests enter pending review. Trusted operators review independent source evidence,
append reviewer/status/notes/resolution and link a corrected snapshot if available.
User submissions never automatically overwrite source data or scores. Explain
uncertainty and preserve the correction audit trail. Identity authority must be
verified before treating a requester as a company representative.
No turnaround SLA is promised in this pilot. External representatives without an
account need an owner-designated verified contact channel. Counsel/owner must approve
retention, escalation, response commitments and appeal process before publication.
